// 记谱法示例 —— 跑 `python mc_piano.py scores/记谱法示例.txt --dry-run` 看解析结果
@title=记谱法示例
@bpm=120
@octave=mid

// ---- 单音，默认每个音 1 拍 ----
1 2 3 4 5 6 7

// ---- 八度：^ 前缀 = 高音，_ 前缀 = 低音（也支持 h1 / m1 / l1）----
_5 _6 _7 1 2 3 ^1 ^2 ^3

// ---- 时值：冒号后是拍数，支持小数和分数 ----
1:2 2:1/2 2:1/2 3:1/4 3:1/4 3:1/2 4:0.75

// ---- 延音线 - ：一个 - 把前一个音延长一拍 ----
1 - - - | 5 - 3 -

// ---- 休止符 0 ----
1 0 2 0 3

// ---- 和弦：用 + 连接，会同时按下 ----
1+3+5 2+4+6 _1+1+^1
^1+^3+^5:2

// ---- 小节线 | 只是视觉分隔，解析时会被忽略 ----
1 2 | 3 4 | 5 6 | 7 - |

// ---- 半音：本琴没有黑键，4# 会就近吸附（默认向下），并给出警告 ----
4# 5b
